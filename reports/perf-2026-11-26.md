# Forecast performance — 2026-11-26

WildWindow **T9.8** warm `/v1/forecast` check (ARCHITECTURE §5.5 / PRD performance).

## Target

- Warm sequential **p95 < 400 ms** on full ingested data.
- Concurrent load via `autocannon` (report p90 / p97.5 / p99; autocannon has no p95 bucket).

## Run locally (full ingested data)

```bash
pnpm db:up && pnpm db:migrate && pnpm db:seed
# GBIF ingest + aggregate + score:refs for scotland and sindh (see worker CLI / docs/RAILWAY.md)
pnpm --filter api dev
# Pick an open/protected taxon id and a res-7 cell inside a beta region:
PERF_TAXON_ID=<id> PERF_CELL=<res7> PERF_START=2026-11-16 pnpm perf:forecast
```

The full command measures sequential warm p95 (100 samples after warmup), runs autocannon, and overwrites this report when the date matches. Gate fails if sequential p95 ≥ 400 ms or autocannon sees non-2xx.

Smoke (CI / no full data — never fails the p95 gate):

```bash
pnpm perf:forecast:smoke
```

When `PERF_TAXON_ID` / `PERF_CELL` / `PERF_START` are unset, or the API is not listening, smoke exits 0 with a skip message. CI also runs the Nest + autocannon smoke test in `apps/api` against seed aggregates (not full GBIF ingest).

## Indexes (T9.8)
